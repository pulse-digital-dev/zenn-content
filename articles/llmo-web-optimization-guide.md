## AI検索が変えたルール

GoogleでURLを10本並べる時代は終わりつつある。

ChatGPT、Perplexity、Gemini——ユーザーが検索する先がLLMに移り始めている。ここで重要なのは、LLMが「どのサイトの情報を参照したか」を選ぶ基準が、従来のSEOとは微妙に違うということ。

被リンクやドメインパワーだけでは足りない。LLMは「そのページが構造化されたデータを持っているか」「引用しやすい形式で情報を提示しているか」を見ている。

この最適化領域を**LLMO（Large Language Model Optimization）**と呼ぶ。

## SEOとLLMOの違い

| 観点 | SEO | LLMO |
|------|-----|------|
| 対象 | 検索エンジンbot | LLM（ChatGPT等） |
| 評価対象 | インデックス＋ランキング | 情報の引用可能性 |
| 重要要素 | 被リンク、E-E-A-T | 構造化データ、機械可読性 |
| コンテンツ | キーワード最適化 | 明確な事実の記述 |
| メタデータ | title / description | schema.org / JSON-LD |

SEOとLLMOは対立しない。SEOの土台の上に、LLMO特有の施策を積む形になる。

## LLMOの4つのチェックポイント

### 1. 構造化データ（JSON-LD）

LLMは構造化データを情報源として優先的に利用する。FAQPage、HowTo、Product、Articleなどのスキーマは、LLMの回答生成時の「素材」になりやすい。

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "LLMOとは？",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "LLM（大規模言語モデル）に自サイトの情報を引用してもらうための最適化手法。"
      }
    }
  ]
}
</script>
```

構造化データがないページは、LLMにとって「読めはするが引用しにくい」テキストの塊になる。

### 2. 機械可読なデータ形式

表（`<table>`）、リスト（`<ul>` / `<ol>`）、定義リスト（`<dl>`）で情報を構造化するだけで、LLMにとっての可読性は大きく上がる。

ダメな例：
```
当社のプランは月額980円のBasicと月額2,980円のProと月額9,800円のEnterpriseの3種類です。
```

良い例：
```html
<table>
  <tr><th>プラン</th><th>月額</th></tr>
  <tr><td>Basic</td><td>¥980</td></tr>
  <tr><td>Pro</td><td>¥2,980</td></tr>
  <tr><td>Enterprise</td><td>¥9,800</td></tr>
</table>
```

同じ情報でも、HTML構造が違うだけでLLMの引用精度が変わる。

### 3. 独自情報の明示性

LLMはどのサイトにも書いてある汎用情報より、そのサイトにしかない一次情報を優先的に引用する傾向がある。

- 独自の調査データ
- 実体験に基づくケーススタディ
- オリジナルの計算ツールや診断ツール
- 特定のニッチに特化した専門知識

汎用的な説明文より「この人しか持ってないデータ」に価値がある。

### 4. 見出し階層の論理性

LLMはページの見出し（h1〜h6）をアウトラインとして認識する。見出し階層が論理的に整理されていると、LLMはそのページの主題と構造を正確に理解できる。

```
h1: LLMOとは
  h2: SEOとの違い
  h2: チェックポイント
    h3: 構造化データ
    h3: 機械可読性
    h3: 独自情報
    h3: 見出し階層
  h2: まとめ
```

h1が複数ある、h2の次にいきなりh4が来る、といった構造の乱れは、LLMの理解を妨げる。

## 自分のサイトをチェックする

ここまで読んで「自分のサイトはどうなんだろう」と思ったら、試す方法がある。

1つ目。ChatGPTに自分のサイトの話題を聞いてみる。引用されるか、スルーされるかで現状がわかる。

2つ目。ツールで自動チェックする。例えばPagePulseというChrome拡張には、LLMOスコアという指標がある。構造化データの有無、機械可読性、見出し階層を自動でチェックして100点満点でスコアを出す。

PagePulseのLLMOスコアは総合スコアの30%を占めている。SEO（20%）よりウェイトが高い。「まだ競合がやっていない領域で差がつきやすい」という考え方で配点を決めている。

## まとめ

LLMOは「今すぐやらないとヤバい」ではなく、「今やっておくと1年後に差がつく」領域。

SEO対策を既にやっている人にとっては、追加コストはそこまで大きくない。構造化データを入れて、情報を表やリストで構造化して、見出しを整理する。これだけで基礎は押さえられる。

誰もやってないからこそ、先にやった人が総取りする。SEOがそうだったように。
