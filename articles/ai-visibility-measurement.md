「自社はAI検索でどの程度見えているのか？」 — この問いに定量的に答えるのが**AI可視性計測**だ。Google検索の順位はSearch Consoleで確認できるが、ChatGPTやPerplexityでの引用率を計測するツールは限られている。本記事では、手動確認から専用ツール、API連携まで、**AI可視性を計測する4段階のアプローチ**を解説する。


## なぜAI可視性の計測が必要なのか


AI Visibility Indexの[104社調査](https://ai-visibility-index.dev/blog/what-is-geo/)が示す数字は衝撃的だ。


- EC業界104社の**98%がAI検索でInvisible**（スコア20点未満）
- 4大AIエンジンの平均スコアはわずか**1.27点/100点**
- SEO上位企業でもAI検索では引用されないケースが多数


問題は、**ほとんどの企業がこの事実を知らない**ことだ。Search Consoleは毎日見ていても、ChatGPTでの自社の可視性は計測していない。「計測しないものは改善できない」 — AI可視性も同じ原則が当てはまる。


## AI可視性計測の4段階


予算と目的に応じて、4段階のアプローチがある。


**AI可視性計測 — 4段階の比較**

| レベル | 方法 | コスト | 精度 | 適している人 |
| --- | --- | --- | --- | --- |
| **Lv.1** | 手動チェック | 無料 | 低い | 個人・初学者 |
| **Lv.2** | Chrome拡張 | 無料 | 中程度 | Web担当者 |
| **Lv.3** | 専用ツール（ランキング） | 月額2,980円〜 | 高い | マーケティングチーム |
| **Lv.4** | API/MCP連携 | 月額980円〜 | 高い | エンジニア・AIエージェント利用者 |


### Lv.1: 手動チェック — 今すぐ無料でできる


最もシンプルな方法は、各AIエンジンに直接質問して自社が言及されるか確認することだ。


:::message
**手動チェック手順**
- ChatGPT、Claude、Perplexity、Geminiをそれぞれ開く
- 「〇〇（自社の業種）でおすすめの企業・サービスは？」と質問
- 回答に自社名が含まれているか確認
- 含まれている場合、どの位置で・どのように言及されているかを記録
:::


手動チェックの限界:


- AIの回答は**毎回異なる**ため、1回のチェックでは信頼性が低い
- クエリ数が増えると手動では限界がある（104社調査では170クエリ × 4エンジン × 20回 = 13,600回の確認が必要）
- 定量的なスコア化ができない
- 競合との比較が難しい


### Lv.2: Chrome拡張 — ワンクリック診断


閲覧中のWebサイトがAI検索エンジンに引用されやすい構造になっているかを、ワンクリックで診断できるのが[Pulse Digital Chrome拡張](https://ai-visibility-index.dev/blog/chrome-extension-guide/)だ。


Chrome拡張が診断する主な項目:


- **構造化データ**: JSON-LD（Organization, Product, FAQPage等）の実装状況
- **セマンティックHTML**: 見出し階層、アクセシビリティ、メタデータの品質
- **AI固有対策**: OGPタグ、llms.txt、サイトマップの設置


20項目を100点満点でスコア化し、改善優先度の高い項目をTOP3で表示する。全ての解析はブラウザ内でローカルに完結し、外部送信は一切ない。


:::message
**Chrome拡張 vs 手動チェック**
- Chrome拡張はサイトの「AI引用されやすさ」の構造的な要因を診断する
- 手動チェックは「実際にAIに引用されているか」の結果を確認する
- 両方を組み合わせることで「原因と結果」の両面からAI可視性を把握できる
:::


### Lv.3: 専用ツール — 業界ランキングとスコア推移


AI Visibility Indexは、**104社のAI可視性を4大AIエンジンで計測し、スコア化・ランキング化**するベンチマークサービスだ。手動チェックやChrome拡張では不可能な計測を自動化している。


**AI Visibility Indexのスコアリング方法論**

| 計測項目 | 詳細 |
| --- | --- |
| **対象企業** | EC業界104社（9業界） |
| **クエリ数** | 170本（汎用 + 購買意図 + 比較クエリ） |
| **AIエンジン** | ChatGPT / Claude / Gemini / Perplexity |
| **実行回数** | 20回/クエリ/エンジン |
| **スコア算出** | 引用率 × 引用品質 × 引用位置 → 0-100点 |
| **更新頻度** | 月次（毎月25日前後） |


ランキングデータから得られるインサイトの例:


- **自社の業界内ポジション**: 9業界のランキングで相対的な位置を把握
- **エンジン別の強弱**: ChatGPTでは見えるがGeminiでは見えない、といったエンジン間格差の発見
- **月次スコア推移**: GEO施策の効果を定量的にトラッキング
- **競合比較**: 同業他社との相対的なAI可視性ギャップを把握


### Lv.4: API/MCP連携 — AIエージェントのワークフローに組み込む


最も高度なアプローチは、[AI Visibility Index MCP API](https://ai-visibility-index.dev/blog/mcp-api-launch/)を使ってAIエージェントのワークフローにデータを組み込むことだ。


MCP（Model Context Protocol）を使うと、Claude DesktopやCursorなどのAIエージェントから直接ランキングデータにアクセスできる。


```
// Claude Desktopでの利用例
// settings.jsonに以下を追加するだけ
{
"mcpServers": {
"ai-visibility-index": {
"url": "https://ai-visibility-index.dev/mcp"
}
}
}
```


MCP APIで提供される3つのツール:


**MCP API提供ツール**

| ツール名 | 機能 | ユースケース |
| --- | --- | --- |
| check_ai_visibility | ドメインのAI可視性スコア照会 | 「自社のAI可視性を教えて」 |
| list_ai_visibility_industries | 9業界サマリー | 「業界全体の傾向を分析して」 |
| get_ai_visibility_methodology | スコアリング方法論 | 「どうやってスコアを算出しているか教えて」 |


:::message
**MCP APIの活用シーン**
- 月次レポートの自動生成: 「自社と競合3社のAI可視性を比較レポートにして」
- 施策効果の検証: 「構造化データ実装前後のスコア変動を分析して」
- 競合調査: 「ファッション業界のTOP10企業のAI可視性を一覧化して」
:::

:::message
**従来のSEOツールとの違い**
DemandMetrics等のSEOツールはGoogle検索順位の計測に特化しており、AI検索での引用率は計測できない。AI可視性の計測には専用ツールが必要だが、SEOツールとの併用が最も効果的だ。
:::


## AI可視性計測を始める3ステップ


1. **Step 1: 無料チェッカーで現状確認**（3秒）[AI Visibility Index無料チェッカー](https://ai-visibility-index.dev/tools/)で自社ドメインのスコアを確認。業界平均との比較が即座にわかる
2. **Step 2: Chrome拡張で改善ポイントを特定**（5分）自社サイトのトップページ、主力商品ページ、FAQページの3ページを診断。改善優先度TOP3に従って施策を実行
3. **Step 3: 月次モニタリング体制を構築**（1時間）MCP APIをClaude Desktopに接続し、月次で「自社のAI可視性レポートを作成して」と依頼するだけで定点観測が完了
