「ChatGPTに聞いたら自社が出てこない」。この不安を、今いるページで即座に検証できるツールが登場しました。


**AI Visibility Checker**は、閲覧中のWebサイトがAI検索エンジンに引用されやすい構造になっているかを、ワンクリックで診断するChrome拡張機能です。構造化データ、セマンティックHTML、AI固有の対策など20項目を解析し、100点満点でスコア化します。


## なぜ「AI対応度」の診断が必要なのか


AI Visibility Indexの調査によると、国内EC業界104社のうち98%がAIに「見えない」状態にあります。平均AI可視性スコアはわずか1.3点（100点満点）。つまり、ほとんどの企業サイトはChatGPT・Claude・Gemini・Perplexityの回答に登場しません。


原因の多くは技術的な構造にあります。構造化データの未実装、OGPタグの欠落、FAQ構造の不在など、AIクローラーが情報を取得しやすい基盤が整っていないケースが大半です。


AI Visibility Checkerは、これらの技術要因を1クリックで可視化します。


## インストール方法


Chrome Web Storeからインストールできます。無料で、アカウント登録も不要です。


1. [Chrome Web Storeのページ](https://chromewebstore.google.com/detail/ai-visibility-checker/bamoimoopkddchiahkfeclgemjgpoifj)を開く
2. 「Chromeに追加」をクリック
3. ツールバーにアイコンが表示されれば完了


:::message
**プライバシーについて**
: この拡張機能はページの解析をブラウザ内でローカルに実行します。外部サーバーへのデータ送信はなく、個人情報は一切収集しません。
:::


## 使い方（3ステップ）


### ステップ1: 診断したいページを開く


自社サイトのトップページ、商品ページ、FAQページなど、AI検索での露出を確認したいページを開きます。競合サイトの診断にも使えます。


### ステップ2: ツールバーのアイコンをクリック


ブラウザ右上のAI Visibility Checkerアイコンをクリックすると、数秒で診断が完了し、ポップアップに結果が表示されます。


### ステップ3: 結果を確認する


診断結果は5つのカテゴリに分かれている。


| カテゴリ | チェック内容 |
| --- | --- |
| 構造化データ | JSON-LD、Schema.org、Organization/Product/FAQPageスキーマの有無 |
| メタデータ | OGPタグ、canonical URL、meta description、title |
| セマンティックHTML | main/article/nav要素、見出し階層（h1-h6）、段落構造 |
| AI固有対策 | llms.txt、sitemap.xml、FAQ構造、robots.txt |
| E-E-A-Tシグナル | 著者情報、公開日、更新日、専門性の表明 |


各カテゴリをクリックすると個別項目の詳細が展開され、項目ごとに合格・不合格が表示されます。


## 診断結果の読み方


### スコアとGrade


総合スコア（0-100点）に加え、A-Fの6段階Gradeが表示されます。


| Grade | スコア範囲 | 解釈 |
| --- | --- | --- |
| A | 80-100 | AI検索に最適化されている。引用される可能性が高い |
| B | 60-79 | 基本は整っているが改善余地あり |
| C | 40-59 | 一部対策済みだが重要な要素が欠落 |
| D | 20-39 | AI対策が不十分。構造的な改善が必要 |
| F | 0-19 | AIにほぼ「見えない」状態。基礎から整備が必要 |


### 改善ポイントTOP3


診断結果の下部には、最もインパクトのある改善アクションがTOP3で提示されます。何から手をつければよいかが一目で分かります。


## 活用シーン


### 1. 自社サイトのAI対応度チェック


トップページ、主要商品ページ、FAQページの3ページを診断するだけで、サイト全体のAI対応状況を把握できます。


### 2. 競合サイトとの比較


自社と競合のスコアを比較することで、どの項目で差がついているかが分かります。AI Visibility Indexの調査データでは、上位企業はOGP実装率100%、FAQ構造の整備率が80%を超えています。


### 3. 改善施策の効果測定


構造化データの追加やFAQページの整備を行った後に再診断すれば、スコアの変化を確認できます。


### 4. クライアント提案資料の作成


SEO/LLMO施策の提案時に、クライアントサイトの診断結果をスクリーンショットで添付すれば、課題の可視化と説得力のある提案が可能です。


## AI Visibility Indexとの連携


Chrome拡張は、閲覧中のページの**技術的な構造**をローカルで診断するツールです。一方、[AI Visibility Index の無料チェッカー](https://ai-visibility-index.dev/tools/)は、4大AIエンジンにおける**実際の引用率**を計測するサービスです。


両方を組み合わせることで、「なぜAIに引用されないのか（技術構造の問題）」と「実際にどの程度引用されているか（引用率データ）」の両面から対策を立てられます。


| ツール | 診断対象 | 方式 | 費用 |
| --- | --- | --- | --- |
| Chrome拡張 | ページの技術構造（20項目） | ローカル解析 | 無料 |
| 無料チェッカー | AIエンジンでの実引用率 | サーバー側データ照会 | 無料（3回） |
| MCP API | 104社ランキングデータ | AIエージェント経由 | 月10回無料 |


## よくある質問


診断データは外部に送信されますか？
いいえ。すべての解析はブラウザ内でローカルに完結します。外部サーバーへのデータ送信、アナリティクス、トラッキングは一切含まれていません。

どのページを診断すべきですか？
まずはトップページ、主力商品ページ、FAQページの3ページを推奨します。これらはAI検索エンジンが最も参照しやすいページです。

スコアを上げるにはどうすればよいですか？
改善ポイントTOP3に表示されるアクションから順に対応してください。特に構造化データ（JSON-LD）の実装とFAQページの整備は効果が高い施策です。AI Visibility Indexの調査では、構造化データ実装企業は未実装企業に比べて引用率が1.4倍高い傾向が確認されています。
